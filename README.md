#Catálogo de Artículos Web
Este proyecto es una migración y evolución de mi sistema de gestión de artículos
originalmente desarrollado como aplicación de escritorio (WinForms)
y ahora transformado en una aplicación web moderna y dinámica.

## 🚀 Tecnologías Utilizadas

*   **Backend:** C#, ASP.NET, APIs REST
*   **Frontend:** ASP.NET Web Forms, HTML, CSS, JavaScript
*   **Base de Datos:** SQL Server (Conexión a base de datos local)
*   **Patrones y Prácticas:** Programación Orientada a Objetos (POO), Arquitectura por capas, Eliminación lógica.

## ✨ Funcionalidades Principales

*   **CRUD Completo:** Alta, lectura, modificación y eliminación lógica de artículos.
*   **Filtros Dinámicos:** Búsqueda de artículos en tiempo real.
*   **Manejo de Imágenes:** Carga de imágenes mediante URL.
*   **Validaciones:** Validación de datos desde el frontend y backend.
